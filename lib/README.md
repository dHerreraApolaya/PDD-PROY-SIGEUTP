# Controlador JDBC

El proyecto utiliza `mssql-jdbc-13.2.1.jre8.jar`. El archivo binario se mantiene localmente y se excluye de Git.

Para preparar una copia descargada del repositorio, obtener esa misma versión desde las [publicaciones oficiales de Microsoft](https://github.com/microsoft/mssql-jdbc/releases) y colocar el archivo en esta carpeta. No es necesario cambiar la versión de Java ni las dependencias.

El controlador es un proyecto de Microsoft con licencia MIT; consultar la licencia de su distribución original.
